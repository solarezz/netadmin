# NetAdmin

Веб-система для управления сетевым оборудованием в локальной сети предприятия. Позволяет мониторить устройства, выполнять команды и открывать WebFig-интерфейс MikroTik прямо из браузера.

---

## Что внутри

- Django-приложение с веб-интерфейсом
- Docker Compose для быстрого запуска
- Поддержка MikroTik (SSH, WebFig) и других сетевых устройств
- Управление пользователями и правами доступа

---

## Требования

- Linux-сервер с Docker и Docker Compose
- Python 3.10+ (если запускаете без Docker)
- Сетевой доступ к управляемым устройствам

## Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <адрес репозитория>
cd netadmin
```

### 2. Создайте файл с переменными окружения

```bash
cp .env.example .env
nano .env
```

Обязательно заполните:

```env
SECRET_KEY=придумайте-длинную-случайную-строку
DEBUG=False
ALLOWED_HOSTS=192.168.1.100  # IP вашего сервера
```

### 3. Запустите через Docker

```bash
docker compose up -d
```

### 4. Создайте первого администратора

```bash
docker compose exec web python manage.py createsuperuser
```

### 5. Откройте в браузере

```
http://<IP-сервера>:8000
```

## Добавление устройств

После входа перейдите в раздел **Устройства** и нажмите **Добавить**.

Что нужно заполнить:

| Поле | Пример | Описание |
|------|--------|----------|
| Название | MikroTik-офис | Любое удобное имя |
| IP-адрес | 10.1.1.2 | Адрес устройства в сети |
| Тип | MikroTik / Generic | Определяет доступные команды |
| Логин / пароль | admin / пароль | Учётные данные SSH |

После сохранения устройство появится на главной странице. Кнопка **WebFig** откроет веб-интерфейс роутера прямо в браузере.

## Доступ к устройствам через сервер-шлюз

Если ваши устройства находятся в изолированной подсети (например, `10.1.x.x`) и доступны только через сервер NetAdmin, нужно настроить маршрутизацию.

### На сервере (Linux)

```bash
sudo sysctl -w net.ipv4.ip_forward=1
sudo iptables -A FORWARD -j ACCEPT
sudo iptables -t nat -A POSTROUTING -s 192.168.56.0/24 -j MASQUERADE
```

### На вашем рабочем ПК (Windows, от администратора)

```cmd
route add 10.1.1.0 mask 255.255.255.0 192.168.56.101
```

Замените `192.168.56.101` на IP-адрес вашего сервера NetAdmin.

### Включить WebFig на MikroTik

По умолчанию MikroTik отключает HTTP-доступ. Включите через раздел **Выполнить команду** в NetAdmin или через SSH:

```bash
/ip service set www disabled=no
```

## Управление пользователями

Перейдите в **Настройки → Пользователи**.

- Создайте учётные записи для каждого сотрудника
- Назначьте роль: просмотр или полный доступ
- Администратор может сбросить пароль любого пользователя


## Резервная копия базы данных

База хранится в файле `db.sqlite3` в корне проекта. Чтобы сделать копию:

```bash
cp db.sqlite3 db.sqlite3.bak
```

При переезде на новый сервер скопируйте этот файл вместе с `.env`.

## Частые проблемы

**Не открывается WebFig**
Проверьте, что маршрут на рабочем ПК прописан и WebFig включён на роутере (см. раздел выше).

**Ошибка подключения по SSH**
Убедитесь, что сервер NetAdmin имеет сетевой доступ к устройству. Проверьте логин и пароль в карточке устройства.

**Сайт не открывается после запуска**
Проверьте логи: `docker compose logs web`. Чаще всего проблема в незаполненном `.env`.
